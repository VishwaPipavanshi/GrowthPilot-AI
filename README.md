# GrowthPilot AI

GrowthPilot AI is a responsive marketing-content website built with React, TypeScript, and Vite. Its writing studio is a browser-only sample experience; it does not connect to a live AI service.

## Requirements

- Node.js 20.19+ or 22.12+
- npm

## Run locally

```bash
npm ci
npm run dev
```

Open the local URL printed by Vite (by default, `http://localhost:3000`).

## Validate and build

```bash
npm run lint
npm run build
npm run preview
```

The production site is written to `dist/`. This folder is generated by the build and should not be committed.

## Deploy

This is a static Vite site and does not require a server or environment variables.

1. Create an empty repository on GitHub.
2. From the project folder, initialize and push the source:

   ```bash
   git init -b main
   git add .
   git commit -m "Prepare GrowthPilot AI for deployment"
   git remote add origin https://github.com/<USERNAME>/<REPOSITORY>.git
   git push -u origin main
   ```

3. Import the GitHub repository into a static host such as Vercel or Netlify.
4. Use `npm run build` as the build command and `dist` as the output directory.
5. No environment variables are required.

For Vercel, the framework preset can be Vite. Netlify can use the same build command and publish directory.

## Demo and privacy

- The writing studio generates sample content locally in the browser.
- The contact form validates and displays its confirmation locally; it does not send or store submissions.
- Pricing and plan details are illustrative only. There are no payments or user accounts.
- No API keys or secrets are needed. Do not put private credentials in client-side environment variables; values exposed to a Vite frontend are public.

## Main scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run lint` | Run the TypeScript check |
| `npm run build` | Create the production build |
| `npm run preview` | Preview the production build locally |
| `npm run clean` | Remove the generated `dist/` folder |
